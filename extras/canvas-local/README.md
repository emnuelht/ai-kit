# Canvas local (reserva)

Usado **só quando a sessão não tem acesso aos Artefatos do Claude** (ex.: Claude Code puro no terminal).
O padrão do kit é o canvas **Design** nos seus Artefatos — veja `.ai/design/CANVAS.md`.

Abra pedindo "abre o canvas" : a IA roda `python .ai/design/canvas-local/serve.py --open`.
Navegar (V) · Comentar (C) · Editar texto (E) · ✓ Aprovar / ✎ Mudar · Desktop/Tablet/Celular · Painel com comentários, estilo e versões.
Comentários vão para `feedback.json`. `bundle.py` gera um HTML único para enviar a alguém.
